# استضافة الويب والتحقق التلقائي (GitHub Pages & CI/CD Actions)

## مفهوم المهارة
أتمتة عملية فحص واختبار جودة الكود ونشره تلقائياً على خوادم الويب عند حفظ التعديلات الجديدة، باستخدام أدوات التكامل والترقية المستمرة (CI/CD) مثل GitHub Actions، بالإضافة إلى نشر المشاريع بسرعة على منصات مجانية مثل GitHub Pages.

## الأهمية في عام 2026
توفر هذه المهارة الكثير من الوقت والجهد وتمنع الأخطاء البشرية أثناء عملية النشر. بمجرد قيامك بكتابة الكود وحفظه، تتولى الخوادم تلقائياً فحصه للتأكد من عدم وجود أخطاء تكسر الموقع، ثم تقوم بتحديث الموقع الحي فوراً.

## التقنيات والأدوات
* **GitHub Actions**: منصة الأتمتة الرائدة لبناء سير عمل مخصص للتحقق والنشر تلقائياً.
* **GitHub Pages**: لنشر واستضافة المواقع التعريفية الثابتة والمحافظ الإلكترونية (Portfolios) مجاناً.
* **Vercel & Netlify**: منصات سحابية ممتازة تتكامل مع GitHub بضغطة زر لنشر المواقع الحديثة (Next.js, React).

## خطة التعلم والتطبيق
1. تصميم موقع معرض أعمالك الشخصي ونشره بالكامل على GitHub Pages بشكل مجاني ومباشر.
2. كتابة ملف إعداد بسيط لـ GitHub Actions باسم (`.github/workflows/deploy.yml`) لتشغيل فحص الجودة والتنسيق (Linter) تلقائياً عند دفع كود جديد.
3. ربط مستودع GitHub بمنصة Vercel ومراقبة ميزة المعاينة التلقائية لكل Pull Request (Preview Deployments).
