# التعاون البرمجي عبر جيت هاب (GitHub Team Collaboration)

## مفهوم المهارة
القدرة على استخدام منصة GitHub السحابية لإدارة المشاريع الجماعية، ومراجعة الأكواد البرمجية للزملاء من خلال طلبات السحب (Pull Requests)، ومتابعة المشاكل والأخطاء البرمجية باستخدام الـ Issues ولوحات المهام (GitHub Projects).

## الأهمية في عام 2026
يعد GitHub بمثابة السيرة الذاتية الفعلية ومحور التعاون البرمجي لجميع مطوري ومصممي المواقع حول العالم. العمل بمهارة داخل المنصة يثبت قدرتك على العمل الجماعي بأسلوب احترافي يتطابق مع بيئات العمل في كبرى الشركات التقنية.

## الأدوات والمفاهيم داخل GitHub
* **Pull Requests (PRs)**: لمراجعة كود المطورين الآخرين ومناقشته قبل دمجه في المشروع الرئيسي.
* **Code Review & Inline Comments**: لتقديم الملاحظات مباشرة على سطور برمجية محددة.
* **GitHub Issues**: للإبلاغ عن المشاكل البرمجية، وتكليف المطورين بمهام محددة وتتبع حالة تنفيذها.
* **GitHub Projects (Kanban Boards)**: لتنظيم المهام وترتيب أولويات الميزات البرمجية المطلوب تطويرها.

## خطة التعلم والتطبيق
1. إنشاء حساب شخصي على GitHub وتكوين ملف تعريف احترافي (README).
2. عمل فورك (Fork) لمستودع مفتوح المصدر وإرسال Pull Request لتعديل بسيط في التصميم أو إصلاح خطأ برمجي.
3. تجربة آلية مراجعة الأكواد مع زميل عمل من خلال التعليق على الأسطر وتأكيد دمج التعديلات (Approval).
