# نظام التحكم في الإصدارات Git (Git Fundamentals)

## مفهوم المهارة
نظام تتبع وإدارة التعديلات التي تطرأ على كود موقع الويب البرمجي بمرور الوقت. يتيح للمطورين حفظ نسخ مختلفة من المشروع، والتراجع عن الأخطاء، والعمل في بيئة تطويرية آمنة دون الخوف من ضياع الكود أو تدمير الأجزاء المستقرة.

## الأهمية في عام 2026
لا توجد شركة تقنية أو فريق تطوير في العالم لا يستخدم Git كمهارة أساسية وإلزامية للتوظيف. يضمن العمل المنظم وعدم تعارض الأكواد البرمجية عند عمل أكثر من شخص على نفس المشروع.

## الأوامر والتقنيات الأساسية
* `git init` & `git clone`: لبدء مستودع محلي أو نسخ مشروع موجود.
* `git status` & `git add` & `git commit`: لمتابعة التعديلات وحفظها في تاريخ المشروع.
* `git branch` & `git merge`: لإنشاء بيئات عمل فرعية وتطوير ميزات جديدة بشكل معزول ثم دمجها.
* `git checkout` / `git switch`: للانتقال الآمن بين فروع الكود المختلفة.

## خطة التعلم والتطبيق
1. تنصيب Git على الحاسوب الشخصي وفهم آلية عمل مناطق العمل الثلاثة (Working Directory, Staging Area, Local Repository).
2. بناء مشروع ويب بسيط وإنشاء فرع (Branch) باسم `feature/navbar` لتصميم قائمة التنقل، ثم دمجها بالفرع الرئيسي `main`.
3. التدرب على التعامل مع تعارض الكود (Merge Conflicts) وحلها بشكل صحيح باستخدام محررات الأكواد مثل VS Code.
