# لغة الهيكلة والأنماط المتقدمة (Semantic HTML & Advanced CSS)

## مفهوم المهارة
كتابة كود HTML دلالي (Semantic HTML) يعبر عن محتوى الصفحة (مثل `<article>`, `<header>`, `<nav>`) وليس مجرد كتل `<div>` صماء، بالإضافة إلى التمكن من CSS الحديثة لبناء واجهات غنية باستخدام التخطيطات المرنة والرسوم المتحركة.

## الأهمية في عام 2026
* **تحسين محركات البحث (SEO):** تقرأ روبوتات البحث الهيكل الدلالي بشكل أفضل لتصنيف صفحاتك.
* **إمكانية الوصول (Accessibility):** تعتمد قارئات الشاشة للمكفوفين على الكود الدلالي للتنقل داخل الموقع.
* **السرعة والكفاءة:** استخدام CSS الحديثة يقلل من الحاجة لملفات جافا سكريبت ضخمة لتنفيذ الحركات البصرية.

## التقنيات والأدوات
* **HTML5**: العلامات الدلالية المحدثة.
* **CSS Grid & Flexbox**: لبناء التصاميم المعقدة والمرنة بشكل فوري.
* **Tailwind CSS**: إطار العمل الرائد لتسريع كتابة CSS مباشرة داخل كود الهيكلة.
* **CSS Custom Properties (Variables)**: لإدارة الألوان والأنماط وسهولة التبديل للوضع الداكن (Dark Mode).

## خطة التعلم والتطبيق
1. تعلم الفرق الكامل بين العناصر الدلالية وغير الدلالية.
2. احتراف نظام الشبكات CSS Grid وبناء تصميم لوحة تحكم (Dashboard) كاملة باستخدامه.
3. استخدام المتغيرات في CSS وتطبيق ميزة التبديل للوضع الداكن بكود نظيف.
