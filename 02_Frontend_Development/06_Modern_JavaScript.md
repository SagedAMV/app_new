# جافا سكريبت الحديثة (Modern JavaScript - ES2026+)

## مفهوم المهارة
التمكن من لغة البرمجة الأساسية للويب لتطوير تفاعلات ديناميكية متطورة، والتعامل مع البيانات واستدعاء واجهات البرمجة (APIs)، وتطوير منطق قوي للواجهة الأمامية باستخدام ميزات ECMAScript الحديثة.

## الأهمية في عام 2026
لم تعد جافا سكريبت مجرد لغة لإضافة حركات بسيطة، بل هي لغة التطوير الأساسية التي تبنى بها التطبيقات السحابية وتطبيقات الويب أحادية الصفحة (SPA). إتقانها بعمق هو الفارق بين مصمم الواجهات العادي والمطور المحترف.

## التقنيات الرئيسية
* **ES6+ Features**: Arrow Functions, Destructuring, Promises, Optional Chaining.
* **Asynchronous JS**: Async/Await للتعامل مع العمليات غير المتزامنة والـ APIs بدون تجميد المتصفح.
* **DOM Manipulation**: التعديل المباشر على عناصر الصفحة وتحليل الأحداث (Events).

## خطة التعلم والتطبيق
1. دراسة أساسيات اللغة وهيكل البيانات الأساسي.
2. فهم مفهوم الـ Event Loop وكيفية عمل جافا سكريبت خلف الكواليس.
3. تطبيق مشاريع عملية مثل جلب بيانات الطقس من API عام وعرضها بشكل تفاعلي وتحديثها دون الحاجة لإعادة تحميل الصفحة.
