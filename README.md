# UniHub — رفيقك الجامعي (Kotlin/Android)

تطبيق Android أصلي لإدارة الحياة الجامعية: ملفات المواد، المحاضرات، المهام، الملاحظات والامتحانات — يعمل بالكامل دون إنترنت وبياناتك تبقى على جهازك.

هذا المشروع هو **إعادة بناء من الصفر** للتطبيق المرجعي `app_university_kotlin` (UniManager)، بنفس اللغة (Kotlin) ونفس الفكرة الرئيسية، لكن بهيكلية أنظف ومنطق أصلح وتصميم أهدأ للعين. تفاصيل ما تغيّر في [تقرير_التحسينات.md](تقرير_التحسينات.md)، وجلسة الفحص وإصلاح كراش الإقلاع في [تقرير_إصلاح_الكراش_والفحص_الشامل.md](تقرير_إصلاح_الكراش_والفحص_الشامل.md).

## ✨ أبرز ما يميز النسخة الجديدة

- 🏗️ **هيكلية نظيفة**: مستودعات لكل مجال + ViewModel مستقل لكل شاشة (لا كائن واحد ضخم لكل شيء)
- 🧭 **تنقّل آمن الأنواع** (Navigation 2.8 + kotlinx.serialization) — بلا مسارات نصية سحرية
- 🧩 **أنواع قوية**: الأولوية ونوع الامتحان ويوم الأسبوع ونوع الملف `enum` بدل نصوص حرة
- 🎨 **ألوان هادئة مريحة للعين** (أخضر مائل للرمادي + محايدات ورقية) مع وضع ليلي منخفض الإجهاد وثلاثة أوضاع للمظهر (نظام/فاتح/داكن)
- 📁 **ملفات حقيقية من الجهاز** عبر منتقي النظام (SAF) تُنسخ داخل التطبيق وتُفتح/تُشارك عبر تطبيقات الجهاز
- 🔔 **تذكيرات ذكية** للامتحانات (قبل يوم، قبل ساعة، عند البدء) والمهام (يوم الاستحقاق) عبر WorkManager
- 📦 **نسخ احتياطي واستيراد** بصيغة JSON (الإصدار 3) مع إعادة جدولة التذكيرات بعد الاستيراد
- 🌌 **شاشة المجرة**: مجلداتك كواكب تدور حول "جامعتك" — رسم خفيف على Canvas مع حركة بطيئة مريحة
- 📝 **ملاحظات مثبتة**، بحث لحظي، حالات فارغة إرشادية، وتحقق من المدخلات برسائل عربية واضحة
- ✅ اختبارات وحدة لمنطق التحقق والتواريخ

## الأقسام

| القسم | الوظيفة |
|---|---|
| الرئيسية | لقطة اليوم: محاضرات اليوم، مهام مستحقة، امتحانات قادمة، إحصاءات وإجراءات سريعة |
| الملفات | مجلدات متداخلة، استيراد ملفات، بحث، مفضلة، فتح/مشاركة/إعادة تسمية/حذف |
| المخطط | 4 تبويبات: المهام، الجدول الأسبوعي، الملاحظات، الامتحانات |
| المجرّة | تصور بصري للمجلدات ككواكب، اضغط كوكباً لفتح مجلده |
| الإعدادات | المظهر، الألوان الديناميكية، النسخ الاحتياطي، مسح البيانات |

## التقنيات

- **Kotlin** + **Jetpack Compose** (Material 3)
- **Room** (KSP) مع مفاتيح أجنبية وفهارس وأنواع قوية عبر TypeConverters
- **Hilt** لحقن التبعيات
- **Navigation Compose** بمسارات `@Serializable`
- **Coroutines & Flow** مع `StateFlow` و`collectAsStateWithLifecycle`
- **WorkManager** للتذكيرات، **DataStore** للتفضيلات
- **SAF + FileProvider** للملفات

## البناء

1. افتح المشروع في Android Studio (2024.1+)
2. انتظر انتهاء Gradle Sync
3. شغّل ▶ على جهاز أو محاكي

**المتطلبات:** JDK 17، Android SDK: compileSdk 35 / minSdk 26، Gradle 8.9 (عبر الـ wrapper)

## ملاحظات

- التطبيق لا يحتاج إنترنت إطلاقاً
- فتح مستندات Office يتطلب وجود تطبيق قارئ مثبت على الجهاز (الفتح عبر `ACTION_VIEW`)
- النسخة الاحتياطية تحفظ البيانات الوصفية وسجلات الملفات، ولا تضمّن محتوى الملفات نفسه
