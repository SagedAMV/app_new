# 🌌 استوديو تصاميم واجهة المجرّة — UniHub

مشروع HTML مستقل (ملف واحد بلا أي اعتماديات) يعرض **30 مقترح أنميشن مختلفاً**
لواجهة «المجرّة» في تطبيق UniHub، بمحاكاة بصرية لواجهات Jetpack Compose
(شريط تنقل سفلي، بطاقات، شرائح، إطار هاتف).

## لماذا هذا المجلد؟

بناءً على ملف `تعليمات.md` — جلسة تصميم واجهة المجرّة:
الواجهة الحالية «مجرّة الثقب الأسود» (كواكب تدور حول ثقب أسود)، والمطلوب
مقترحات **مختلفة كلياً** تعرض بيانات المجلدات والملفات بحركة بطيئة مريحة للعين.

## طريقة الاستخدام

1. افتح `index.html` في أي متصفح حديث.
2. تصفّح المقترحات الثلاثين — كل بطاقة معاينة حيّة متحركة.
3. اضغط على البطاقة التي تعجبك لتحديدها (يمكن تحديد أكثر من واحدة).
4. اضغط **«تصدير اختيارات.MD»** — يُنزَّل ملف `اختيارات.MD`.
5. أرفق ملف `اختيارات.MD` في جذر هذا المستودع، وفي الجلسة القادمة
   يقرؤه الوكيل وينفّذ الاختيارات على `GalaxyScreen.kt`.

## ضمانات التصميم

- كل الحركات **بطيئة ومريحة للعين** وفق فلسفة سمة التطبيق (`ui/theme/Color.kt`).
- الألوان من لوحة التطبيق فقط، بما فيها لوحة ألوان المجلدات `FolderPalette`.
- كل مقترح يعرض **اسم المجلد وعدد ملفاته ولونه** — نفس بيانات الشاشة الحالية.
- كل بطاقة تتضمن **ملاحظات تنفيذ Jetpack Compose** الدقيقة للمقترح.
- التحديد محفوظ في المتصفح (localStorage) فلا يضيع عند إعادة فتح الصفحة.
- الأداء: تُرسم البطاقات المرئية فقط وتتوقف الحركة عند إخفاء التبويب.
