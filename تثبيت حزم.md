



# التثبيت وتجنّب الأخطاء — خلاصة تنفيذية لوكيل آلي

## 1) التوليفة الإجبارية (لا تجرّب غيرها أولاً)

| المكوّن | النسخة |
|---|---|
| JDK | Temurin 17 |
| Gradle | 8.9 |
| Android Gradle Plugin (AGP) | 8.7.3 |
| compileSdk / platform | 35 |
| build-tools | 35.0.0 |
| JUnit | 4.13.2 |

> Gradle وAGP مقيدان ببعضهما — لا تُرقِّ أحداً دون مراجعة جدول التوافق الرسمي.

## 2) أوامر التثبيت بالترتيب الإجباري

### أ) تنزيل JDK + cmdline-tools + Gradle (معاً)

```bash
export LC_ALL=C.UTF-8
mkdir -p ~/android-toolchain ~/android-sdk/cmdline-tools ~/downloads
cd ~/downloads

curl -sSL -o jdk17.tar.gz  "https://api.adoptium.net/v3/binary/latest/17/ga/linux/x64/jdk/hotspot/normal/eclipse"
curl -sSL -o cmdtools.zip  "https://dl.google.com/android/repository/commandlinetools-linux-13114758_latest.zip"
curl -sSL -o gradle.zip    "https://services.gradle.org/distributions/gradle-8.9-bin.zip"

tar -xzf jdk17.tar.gz -C ~/android-toolchain
mv ~/android-toolchain/jdk-17* ~/android-toolchain/jdk17

unzip -q cmdtools.zip -d ~/android-sdk/cmdline-tools
mv ~/android-sdk/cmdline-tools/cmdline-tools ~/android-sdk/cmdline-tools/latest   # ← إجباري

unzip -q gradle.zip -d ~/android-toolchain


ب) التراخيص قبل أي تثبيت حزم (وإلا رُفضت بصمت)

```bash
export JAVA_HOME=$HOME/android-toolchain/jdk17
export ANDROID_HOME=$HOME/android-sdk
export PATH=$JAVA_HOME/bin:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH
yes | sdkmanager --sdk_root=$ANDROID_HOME --licenses
```

ج) حزم SDK + حفظ البيئة

```bash
sdkmanager --sdk_root=$ANDROID_HOME "platform-tools" "platforms;android-35" "build-tools;35.0.0"
sdkmanager --sdk_root=$ANDROID_HOME --list_installed   # تحقق مستقل

cat > ~/android-toolchain/env.sh <<'EOF'
export JAVA_HOME=$HOME/android-toolchain/jdk17
export ANDROID_HOME=$HOME/android-sdk
export ANDROID_SDK_ROOT=$HOME/android-sdk
export PATH=$JAVA_HOME/bin:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools:$ANDROID_HOME/build-tools/35.0.0:$HOME/android-toolchain/gradle-8.9/bin:$PATH
EOF
echo '[ -f $HOME/android-toolchain/env.sh ] && source $HOME/android-toolchain/env.sh' >> ~/.bashrc
source ~/android-toolchain/env.sh
```

3) ملفات المشروع الإجبارية (للتحقق)

local.properties (بدونه يفشل Gradle):

```properties
sdk.dir=/home/user/android-sdk
```

gradle.properties (حرج للبيئات ≤2GB RAM):

```properties
org.gradle.jvmargs=-Xmx1024m -XX:MaxMetaspaceSize=512m -Dfile.encoding=UTF-8
org.gradle.daemon=false
org.gradle.parallel=false
org.gradle.workers.max=1
android.useAndroidX=true
android.nonTransitiveRClass=true
```

build.gradle (الجذر):

```groovy
plugins { id 'com.android.application' version '8.7.3' apply false }
```

app/build.gradle (المقتطفات الحرجة):

```groovy
android {
    namespace 'com.example.demo'
    compileSdk 35
    defaultConfig { minSdk 24; targetSdk 35 }
    compileOptions {
        sourceCompatibility JavaVersion.VERSION_17
        targetCompatibility JavaVersion.VERSION_17
    }
    testOptions { unitTests { returnDefaultValues = true } }
}
dependencies { testImplementation 'junit:junit:4.13.2' }
```

4) التشغيل والتحقق

```bash
source ~/android-toolchain/env.sh
cd ~/android-demo
gradle testDebugUnitTest --no-daemon --console=plain
```

التحقق الحقيقي (لا تكتفِ بـ"BUILD SUCCESSFUL"):

```bash
grep -o 'tests="[0-9]*" skipped="[0-9]*" failures="[0-9]*" errors="[0-9]*"' \
  app/build/test-results/testDebugUnitTest/*.xml
# المتوقع: tests="11" skipped="0" failures="0" errors="0"
```

5) 🚫 جدول التجنّب (أخطاء وقعت فعلاً)

❌ تجنّب ✅ البديل السبب
ترك cmdline-tools باسمه mv cmdline-tools cmdline-tools/latest بدونه: Could not determine SDK root
تثبيت الحزم قبل التراخيص yes \| sdkmanager --licenses أولاً رفض صامت
set -e مع && أسطر مستقلة فشل داخل && لا يوقف set -e
tail مباشرة على سجلات Gradle/sdkmanager tr '\r' '\n' < log \| tail محارف \r تبتلع النتيجة
javac بلا ترميز LC_ALL=C.UTF-8 + -Dfile.encoding=UTF-8 فساد المحارف غير ASCII
sed بأنماط عامة لإصلاح الكود عدّل برقم السطر (10s/…/…/) أو أعد كتابة الملف نمط return a + b; طابق دالتين فكسر add
ترك Gradle daemon في ≤2GB --no-daemon + -Xmx1024m + workers.max=1 استنزاف الذاكرة
نسيان local.properties sdk.dir=<مسار SDK> Gradle لا يجد SDK
الاعتماد على "BUILD SUCCESSFUL" اقرأ XML: failures="0" "ناجح" قد يعني 0 اختبارات
